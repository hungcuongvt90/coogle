# 1.3.3 本地审查与构建记录

日期：2026-10-13 至 2026-10-14，Asia/Shanghai。前期仅在本地整合和构建；2026-10-14 用户授权发布 1.3.3 测试版、上传 APK 与附属模块 ZIP，并将整合代码推送主分支处理 PR #6。保留现有 Release 和 GitHub 首页文案。

## 整合与修复

- 保留已实机确认可用的 ColorOS 相机 Lens 原生菜单、点击跳转和 Google OEM 资格声明。
- 在本地合并 PR #6 原提交 `6bcd40d1b9b8affe6635509d3f9a87a892c1ffa2`，保留 Andrea-lyz 的作者身份；嵌入 ZIP 根据两侧源码重新生成，避免覆盖已有开关同步修复。
- 新增独立 `payloadRevision=2`，保留 `controlVersion=1`。安装器在 active/staged 目录返回 READY/PENDING 前验证修订号和必要的挂载辅助脚本；旧 1.3.2、缺失/非法修订号返回 UPDATE_REQUIRED，兼容的较新 payload 不触发降级。
- 附属模块沿用 Hey Google 开关的安装提示，按用户要求删除独立管理入口。已知安装仍可自动复查；首次打开且未使用附属模块的用户不会被主动请求 Root。更新保留 Hey Google 选择，只有从开启 Hey Google 流程明确安装时才开启它。
- 将 Google 目录挂载标记处理集中到 mount-google.sh，由安装和 post-fs-data 复用。按 KernelSU 选用的 metamodule 及其启用/安全模式状态决定 .replace，不依赖尚未加载的 NoMount 驱动。失败时保留 APK 并标记 component-error/skip_mount。

## 审查与精简

重点核对安装/升级、Root 与 LSPosed 配置同步、相机点击与资格、Hook 回滚、DexKit 缓存、资源引用、现有助理/翻译/钱包路由。

删除两个未引用的旧 PNG（coogle_icon、coogle_monochrome），将启动图标移到符合 minSdk 的通用资源目录，删除已被共享挂载协调器替代的安装时驱动探测分支，避免保留独立的重复升级测试启动脚本。反射兼容层、失败恢复、应用/系统上下文缓存和许可证说明均有实际用途，保留。

构建前验证：现有 APK 回归套件通过；升级状态覆盖 13 个场景；附属模块原 24 项与新挂载/升级测试通过。后续增加的安全模式、remove 和标记失败用例也通过（附属模块共 35 项）。后端识别反转和 payload 最低修订号降为 0 的两个隔离变异均被回归测试拒绝。

完整 lintRelease 无阻断错误。未使用 PNG 已删除，启动资源已移至通用目录；本地遗留的空 mipmap-anydpi-v33 目录仍触发 lint 提示，自动审批拒绝删除该空目录（仅返回 blocked by policy），目录不进入 APK。仍保留反射内部 API、LSPosed 导出 Provider、进程级系统上下文等预期警告，没有通过 suppression 降低检查标准。

## 2026-10-14 原生相机资格改造

按用户要求替换模块自定义相机资格策略，恢复国行 Lens Presenter 缺失的普通拍照分支。儿童模式、功能支持、正常入口、前后摄与锁屏状态均调用现有相机接口；锁屏条件与提取的国际版普通分支一致，使用原生锁定状态与原生安全 UI 标记的组合。其他模式、拍摄过程中的显隐、菜单与点击处理沿用原代码。删除 CameraLensPolicy、其旧测试和旧方案的专用 Intent/服务模拟，补充原生回调与缓存迁移测试。

生产 DexKit 定位和完整绑定在连接的国行手机上通过了两版实际 Camera APK（CN 7.006.125、国际版 6.070.230），缓存读取也通过。主动移除儿童模式判断的变异被新回归测试拒绝。全部 JVM APK 回归、最终构建与 lint 通过。附属模块 35 项测试在本轮审查前已重跑通过，随后源码和 ZIP 未修改。

额外补跑现有 Google Lens Android DEX 回归时，ADB 在执行前变为 offline，因此该额外设备测试未成功执行；对应 JVM Lens/缓存回归已通过。新版原生相机 Hook 尚未安装验证实时 UI 和锁屏/解锁过程；此前用户确认成功的是旧测试包。

后续按用户要求删除相机智能镜头开关及其描述，相机与 Google 作用域内默认加载原生相机资格修补。旧 camera_lens=false 配置不再读取；独立 Google 智能镜头开关保留。删除附属管理 UI 回调、显式管理分支及相关文案，恢复原安装提示。继续保留 payloadRevision=2、NoMount 协调、Hey Google 选择保留与失败回滚。修改后的相机测试在偏好均为 false 时通过，且确认零次读取旧开关。最终复审未发现新增阻断问题；整套 APK 回归、lint、构建和附属模块 35 项测试通过。新版未安装，未推送 GitHub。

# 作用域申请与智能镜头开关：本地修改和审查

日期：2026-10-14。基线为已发布 1.3.3 的 e699681。本轮只做本地修改和构建，不发布 GitHub，不修改首页和已有 Release。

## 已实现

- 只在用户把功能开关从关闭切到开启时检查一次对应作用域。只申请缺少的应用；全部已勾选时直接保存开关，不显示申请。启动应用、恢复前台、框架连接均不自动申请。
- 请求期间合并重复操作，拒绝或部分批准不会开启功能。再次主动开启可以重试。服务断开后忽略旧回调；界面重建通过现有弱引用连接接收结果，不把 Activity 保存到框架监听器。
- 手动从 LSPosed 取消作用域不会修改 Coogle 保存的功能开关。重新打开应用也不申请；关闭再开启时才检查缺少的作用域。
- 相机智能镜头和 Google 进程内的 OEM 相机资格声明都归入现有“Google智能镜头”开关。开启时申请 Google 和相机作用域。启动时关闭则跳过相机 DexKit 定位；已安装的回调在关闭时保留原生结果。锁屏等资格条件继续使用相机原生逻辑。
- 删除钱包小字中的默认付款应用设置要求，以及模块状态弹窗中的系统兼容性检查文字。系统兼容性代码本身保留。
- 按用户后续要求取消自动设置默认付款的方案，删除相关新增实现、Root 执行器提取和测试。钱包仍使用系统现有默认付款选择；附属模块源码和嵌入 ZIP 没有变化。

## 仅提供方案，尚未实施

### 初次打开状态闪动

当前状态默认是未连接及默认开关值，收到框架服务后才显示远程偏好。建议先显示中性的连接中状态，在连接并读完设置后一次性显示最终状态；同一进程重开使用已确认的状态。冷启动可缓存上次的开关值用于只读展示，确认连接前禁止修改。不要缓存“已激活”作为当前事实，也不要用动画掩盖错误的初始值。

### 附属模块检测慢或误判

目前 Root 操作共用串行执行器，检查超时为 20 秒，可能包含首次授权等待。第一次未使用附属模块时不会主动请求 Root，外部手动安装的模块也可能尚未被记为已知。未连接设备，未测量真实耗时。

建议把检查与配置同步分开，复用一次轻量 Root 查询，保留上次确认结果并在后台刷新，提供主动重查入口。首次未检查显示未确认，而非未安装；授权拒绝和超时显示检测失败，不能当作未安装。

### Hey Google 小字的含义

按用户提出的方向，LSP 仅显示附属模块安装/实际启用状态：未安装、已安装并启用、已安装请重启设备。正常状态不随 Hey Google 开关改变，也不增加 Voice Match 或 DSP 的细分判断；详细情况继续在 KSU 模块简介中显示。

安装/升级待生效应与 `features.conf` 中 Hey Google 选择待应用分开判断。识别 KSU 手动禁用和检测失败时需要独立的异常提示，避免归为未安装或已启用。若要确认当前启动实际应用了模块，可以记录当前启动的应用标记，防止沿用上一轮启动的配置文件误报已启用。

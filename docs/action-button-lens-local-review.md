## Final behavior

- Add an independent, default-off `action_button_lens` switch in 系统设置, immediately before Google钱包. Title: 快捷键智能镜头. Description: 将快捷键中AI拍一拍替换为智能镜头.
- Only this switch controls the shortcut replacement. Existing Lens/camera behavior remains under `lens`. Required scopes are Google + com.oplus.gesture for the new switch, Google + com.oplus.camera for the existing switch. Scope authorization uses the existing explicit-enable flow; no Root is needed for this setting.
- When enabled, replace the native AI scanner label with 智能镜头. The native summary remains 长按使用%s. The central Lens vector is colored; the tab is white. Native sizes, padding, selected/unselected alpha, scale and transitions remain unchanged. On disable, hooks delegate to native behavior; reopen/restart the gesture app to refresh existing views.
- Long-press package availability checks now substitute Google for the original scanner package and then execute the native check with its original user/context; hidden-app restrictions remain intact. The short-press service binder is replaced only for the exact scanner component and scene, delegating to the existing native fluid-cloud/side-hint renderer with module-owned Lens artwork and 长按使用智能镜头. No AI scanner service is started. Both adaptations are gated by the new switch and successful resource/Google initialization.
- The copied Intent targets Google's exported direct-intent alias com.google.android.apps.lens.MainActivity with ACTION_VIEW and google://lens, preserving native flags/extras. No alternate Google URI route is retained. The exact scanner scene/owner/action triple is required. Key timing, game/pocket restrictions, current user and SpruceLauncher animation are retained.
- The Lens SDK caller callback returns the actual gesture application's package through lens_activity_params/lens_activity_binder. Native ActivityOptions are passed through unchanged; the extra ContextImpl identity-sharing Hook has been removed. No identity spoofing or authentication bypass is introduced.
- Google native OEM integration declaration includes only enabled callers; both switch combinations work independently, existing callers are retained and not duplicated. No system property is written by the module.
- The temporary standalone Lens destination and native-only-UI experiment are removed. The standalone Lens app is not required. Missing/ambiguous targets, unsupported resources or unresolved Google destination retain native behavior.
